Overall layout

Three-column structure:

Left navigation sidebar
Main building grid
Right inspector panel

The page is designed so the user can browse visually, select one building, and immediately customize it without leaving the screen.

Visual style

The style is:

Modern
Lightweight
Rounded
Soft shadows
Minimal color
Large thumbnails

The main background is off-white/light gray. Cards are white with subtle borders and rounded corners. Blue is used only for active states and primary actions, which keeps the interface calm.

Left sidebar

The sidebar is dark navy/black, giving the app a professional tool feel.

It contains:

App name
Dashboard
Buildings
District status card
Settings

The active tab, Buildings, uses a bright blue pill highlight. This makes navigation obvious without cluttering the screen.

Top filter row

The top row is simple:

Search address
Neighborhood dropdown
Type dropdown
More filters

This supports the MVP goal: find a building quickly without exposing template/debug tools yet.

Building grid

The center is a 4-column grid of large building cards.

Each card includes:

Street-view thumbnail
Address
Type + Neighborhood
Customized status
Overflow menu

The selected card has a blue border. Customized buildings get a small green dot and label. This is the only status that matters for the MVP.

Right inspector panel

The right panel shows the selected building.

It includes:

Address title
Customized badge
Large preview image
Building details
Preview toggle
Actions

The inspector avoids advanced data. It only shows what helps the user decide whether to customize the building.

Primary action

The main call-to-action is:

Customize Building

It is a large blue button near the bottom of the inspector. This clearly establishes the workflow:

Browse → Select → Customize

The secondary action is:

Reset to Generated

This only appears because the selected building has already been customized.

MVP design rule

This page intentionally avoids:

Templates
Generation stats
Draw calls
Bulk export
Source tracing
Advanced 3D editing

The whole tab is focused on one job:

Pick a building and open its customization canvas.
