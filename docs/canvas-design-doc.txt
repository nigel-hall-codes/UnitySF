Building Customization Canvas
UX Design Specification v1.0
Purpose

The Building Customization Canvas allows users to create building-specific overrides.

Unlike the Template Editor, this screen is not procedural.

Changes made here affect:

One Building
One Facade
One Location

Examples:

Store signs
Murals
Artwork
Decals
Awnings
Planters
Lights
Custom storefront branding

The goal is to quickly transform a procedurally generated building into a unique landmark without leaving the iPad workflow.

Design Philosophy

This screen should feel closer to:

Procreate
Figma
Canva

than:

Blender
Maya
Unity

The user is decorating a facade.

They are not editing geometry.
